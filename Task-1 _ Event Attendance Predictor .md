# **ML Task: Event Attendance Predictor**

Build a machine learning model that predicts whether a student who registered for a club event is likely to actually attend.

### **Dataset**

Use the provided event registration dataset. It contains information such as:

* Number of previous events attended  
* Number of events the student registered for  
* Registration time  
* Event type  
* Whether the event is technical or non-technical  
* Previous participation in the club  
* Attendance status

And more

**Train Dataset:** [https://docs.google.com/spreadsheets/d/1-kJpEan0ubFgaT0XIqC6GZdevqOnx7qmdsP1bBuEH5g/edit?usp=sharing](https://docs.google.com/spreadsheets/d/1-kJpEan0ubFgaT0XIqC6GZdevqOnx7qmdsP1bBuEH5g/edit?usp=sharing)

**Test Dataset:** 

[https://docs.google.com/spreadsheets/d/1eKM8R6Ew2woVv6cm9AZFbnbYrDTbrlIBmkLuotl8iKQ/edit?usp=sharing](https://docs.google.com/spreadsheets/d/1eKM8R6Ew2woVv6cm9AZFbnbYrDTbrlIBmkLuotl8iKQ/edit?usp=sharing)

### **What you need to do**

1. Clean the dataset and handle missing or inconsistent values.  
2. Perform the required preprocessing and convert categorical data into a suitable format.  
3. Train a classification model to predict whether a student will attend the event.  
4. Evaluate your model using:  
   * Precision  
   * Recall  
   * F1-score  
5. Use the trained model to predict attendance for new registrations.

### **Expected Output**

Your model should be able to give predictions such as:

* Student A →  **87% likely to attend**  
* Student B →  **32% likely to attend**

### **Optional but effective**

Based on your analysis, identify 2–3 useful insights that could help the club improve event attendance. For example, you might find certain registration patterns or types of participants that are more likely to attend.
